# 《长夜灯》剧情与谜题蓝图（M0）

日期：2026-09-06。上游文档：[文字解谜游戏-需求文档](文字解谜游戏-需求文档.md)。
本文档是内容圣经：场景清单、跳转条件、谜题-线索映射、结局达成条件全部在此定死，
`changye.html` 的内嵌 JSON 数据与此一一对应，`tests/changye_verify.mjs` 按本文档做可达性自动校验。

**基调（锈湖式）**：诡、静、暗。每个场景是一只"谜题盒"；谜题的核是文字线索，形是可把玩的机关；
谜面与剧情隐喻互扣——灯吃名字，账本记灯油，画像少一个人。

## 1. 世界观与人物

暴雨夜，书生**沈砚**投宿荒山中的**长夜客栈**。山中旧俗：过山人在灯谱上"落名"，灯亮一宿，人保平安。
真相：**灯吃记忆**。名字落进灯谱，夜里灯便一点点吸走此人的记忆；天亮时人还记得回家的路，
却想不起自己是谁——留下来的，成了客栈里沉默的影工。

- **沈砚**（玩家）：赶路书生，随身一盏祖传旧灯笼——灯骨与客栈的灯同源，是终章的钥匙。
- **乌老板**：掌柜。常年戴斗笠，脸藏在灯影里。每一代守灯人把脸喂给了灯。
- **阿九**：哑巴伙计。眼神空空。真名**阿昭**，名字在灯谱上，记忆在地窖坛里。
- **白先生**：前任住客，画师。他画进画里的东西会消失。他发现了灯的秘密，
  把真相和自己画进了同一幅画，人化作了禁房里的灯影。

## 4. 灯花（隐藏收集，共 7 枚）

藏在"经不起第二眼的地方"，点亮 HUD 计数：①山道路碑底座 ②破庙签筒底 ③大堂匾额后 ④柜房账本封皮夹 ⑤禁房画箱底 ⑥地窖坛阵之后 ⑦祠堂牌位之后。全部 7 枚 + 真结局条件 = 隐藏结局（见 §5）。

## 5. 结局达成条件（终章·灯房）

进入灯房本身需要：**记忆之画**（挂上祠堂空画架，画中的门成真）+ `summons_zishi`。

| 结局 | 名称 | 触发 | 条件 |
|---|---|---|---|
| E1 | 天亮启程（普通） | 按规矩落名安歇，什么都别碰 | 无（始终可选） |
| E2 | 灯灭（坏） | 直接剪断灯芯 | 持**灯芯剪**（但没有给灯"新的名字"） |
| E3 | 灯长明（真结局） | 以画换名：把记忆之画烧进灯里，名牌还阿昭，灯笼引走火种 | 持**记忆之画** + **阿昭名牌** + `knows_secret` |
| E4 | 灯影中人（隐藏） | 接过斗笠，做自由的守灯人 | E3 全部条件 + **灯花 7/7** |

## 6. 线索合成（笔记系统自动推论）

- 持有「碑文：灯下不问来路」+「藏头诗：灯吃人名」→ 自动推论：*"灯下不问——不是不问来路，是灯不问，只吃名。"*
- 持有「账本疑点」+「乌老板日记」→ 自动推论：*"灯谱上三百六十一个名字，账本里三百六十一份灯油。"*

## 7. 可达性论证（无死档）

1. **关键道具均不消耗**：当票、绳、桶、灯油、灯笼、名牌、画、剪刀都是"看过/持有"语义，用后仍在。
2. **条件图无环依赖**：P0→P1→{P2,P3,P4,P5}→P6(P4,P3 前置的钥匙/铜镜)→P7~P10→结局，
   是严格分层的前向图；每一前置的获取路径不经过任何"不可回访"的场景（全部场景可反复进出）。
3. **每道谜题的答案线索在游戏内出现且可回看**（§3 映射表逐行成立），且每个谜题配两级提示 + 终级兜底。
4. **E1 无条件可选** ⇒ 任何存档状态都不可能卡到无法推进剧情。
   以上 1~4 由 `tests/changye_verify.mjs` 在 JSON 数据上自动复核（按落名三分支做单调闭包，
   断言全场景/谜题/热点/出口/结局可达 + 灯花可集齐），当前 7/7 通过。
